# 生词本 WordBook

一个 Windows 本地“记录陌生单词”工具：阅读英文论文/网页时遇到不认识的词，**选中复制 → 按 `Ctrl+Alt+Shift+W` → 回车**，词和原句就存进词库；随后后台会自动联网补音标/中文释义，并可用 DeepSeek **结合原句**给你一段教学式讲解（这句话里什么意思、为什么、怎么换种说法、怎么记住它）。

## 快速开始

1. 双击 **`启动生词本.vbs`**（首次会自动编译，之后秒开）。
2. 浏览器会自动打开词库页面，同时任务栏托盘出现 📖 图标。
3. 在任何程序里选中单词或整句 → 按 `Ctrl+Alt+Shift+W` → 弹框回车/勾选保存。
4. 回浏览器页面查看：每个词都显示**记录时间**和**来源原句**，点开可编辑、可让 AI 重新讲解。

> 再双击一次启动脚本：如果程序已经在运行，只会重新打开浏览器页面，不会重复启动。

## 配置 DeepSeek（可选但推荐）

复制根目录的 `.env.local.example` 为 `.env.local`，填入：

```ini
DEEPSEEK_API_KEY=你的key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
WORDBOOK_PORT=17812
```

保存后**重启生词本**（托盘图标 → 退出，再双击启动脚本）。

- key 只保存在本地 `.env.local`，该文件已被 `.gitignore` 忽略，不会被提交，也不会出现在日志里。
- 不配置 key 也能用：记录、查看、编辑、备份都不受影响；系统会用免费词典接口自动补音标和中文释义，AI 讲解留到配好 key 之后点“AI 重新讲解”。

## 使用场景

### 记录单个生词

选中 `serendipity` 复制 → 按 `Ctrl+Alt+Shift+W` → 弹框已带好单词 → 回车。

### 从句子记录多个生词

复制一整句 → 按 `Ctrl+Alt+Shift+W` → 弹框列出句中的候选生词（常见词已自动隐藏）→ 勾选一个或多个 → 保存。原句会作为例句和 AI 讲解的上下文保存。

### 页面里能做什么

- 看列表：单词、音标、原句、讲解摘要、记录时间一目了然；
- 搜索与筛选：关键词搜索，按“讲解中 / 待重试 / 未讲解”筛选；
- 点开词条：修改词义、原句、AI 讲解内容，删除，手动重查词典或重讲；
- 备份 / 导入：导出 JSON 备份，可随时恢复或换电脑。

## 数据保存在哪

- 词库文件：`data/words.json`（可整个文件复制备份，已被 git 忽略）。
- 网页用 127.0.0.1 本机端口访问，不对外网开放。

## 快捷键与托盘

- `Ctrl+Alt+Shift+W`：弹出记录框；若被其他软件占用，程序会自动改用 `Ctrl+Alt+Shift+K`。
- 弹窗打开时**再按一次热键会直接关闭它**，不会重复弹出；按住弹窗空白处可拖动。
- 托盘右键：打开生词本、手动记录、开机自启开关、退出。
- 勾选“开机自启”后，Windows 登录时程序会在后台静默启动（不弹浏览器）；需要看词库时再双击启动脚本或点托盘图标。
- 页面快捷键：`N` 记一个词，`/` 聚焦搜索。

## 常见问题

- **记录后没有 AI 讲解？** 看页面词条右上角状态：显示“讲解中”说明后台正在处理；显示“未讲解”说明还没配 `.env.local` 里的 key，或词条没有原句。
- **热键没反应？** 可能是被其他程序占用，先到托盘菜单里点“手动记录一个词”；或换一个热键（改 `Gui.cs` 里注册的按键后重新编译）。
- **怎么退出？** 托盘图标右键 → 退出。
- **想彻底重来？** 直接删除 `data/words.json`，下次启动自动建空词库。

## 开发

```powershell
dotnet build desktop\Wordbook.csproj -c Release
dotnet run --project desktop\Wordbook.csproj -- --serve   # 只启动网页服务，用于调试
```

网页为原生 HTML/CSS/JS，无构建依赖；桌面端为 .NET 10：记录弹窗用 WPF（高分屏自适应、可拖动），托盘与全局热键常驻，内嵌本地 Web 服务。词典用免费接口 dictionaryapi.dev / MyMemory，AI 讲解走 DeepSeek 兼容接口。
